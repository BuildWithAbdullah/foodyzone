# 🍽️ FoodyZone - Responsive Food Ordering App

FoodyZone is a fully responsive and modern food ordering web application built using **React** and **Vite**, with backend support using **Node.js** and **Express**. It allows users to browse food items, filter by category, and search dynamically — all with a clean, user-friendly UI.

---

## 🔧 Features

- ✅ Fully responsive on all screen sizes
- 🔎 Real-time search functionality
- 🍔 Filter by category: All, Breakfast, Lunch, Dinner
- 📦 Food cards with image, name, description, and price
- 🧠 Data fetched via API calls from a custom backend
- 🎨 Simple, clean, and modern UI
- 🚀 Fast loading with Vite

---

## 🛠️ Tech Stack

- **Frontend:** React, Vite, HTML5, CSS3
- **Backend:** Node.js, Express.js
- **Styling:** CSS Flexbox, Media Queries
- **Deployment:** (optional - you can include if deployed) Netlify / Vercel for frontend
